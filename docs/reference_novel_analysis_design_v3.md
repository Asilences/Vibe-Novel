## 1. 采用方案：四层长期保留，一条使用流程

两种说法不是替代关系：“原文库→结构拆书→提炼→检索调用”描述工作过程；“原文、内容结构、方法、表达”描述长期保留什么。**以内容结构为中心，四层双向回查；方法卡与Skill是入口，不是全书的替代物。**

| 资料层 | 长期保存的内容 | 能回答的问题 |
|---|---|---|
| 原文层 | 不变的原件、文本版本、原书卷章、附记、异常、清理映射、精确位置 | 实际写了什么？这项解释能否回原文核对？ |
| 内容结构层 | 逐章功能、阶段与全书地图、事件因果、人物/关系变化、信息差、线索、节奏与题材资源 | 为什么这样安排？多章怎样形成准备、转折与后果？ |
| 方法层 | 从结构分析得到的可迁移步骤、前置条件、变体、反例、失效信号及检查项 | 我的新作遇到同类问题，有哪些不同做法？ |
| 表达层 | 视角/叙述距离、对白功能、细节选择、描写密度、句段节奏、情绪呈现及语境 | 怎样把相同剧情目的写得具体、自然、有区别？ |

书目、版本、来源证据、覆盖、预算和作者评价贯穿四层，不另堆成互不相通的“库”。表达观察保留对应场景及人物，结构和表达可以共同解释同一段的作用。来源陈述、分析者解释、新作建议必须分开。

流程为：原件与目录核对 → 可回溯的分章/分册 → 全章基础阅读 → 完整阶段精读与跨章回查 → 全书地图 → 跨书比较 → 候选方法/表达方案 → 本书按任务调用 → 作者评阅与补读。分析允许返回前面步骤修正，不能归并一次就丢弃原文与逐章结果。

## 2. “充分吸收”的目标与边界

现有方案确实偏重少量选段和方法卡，容易漏掉长篇真正重要的因果积累、阶段衔接、日常关系和长期信息安排。本次将**每份当前文件的全部正文进入基础分析**作为目标，重点精读决定深度，不决定其他章节是否保留。

完成标准包括：

1. 原始文件完整保存；每段正文有明确去向。附记、广告、目录、重复与异常单列，不无声丢弃。
2. 每章有基础结构分析和表达观察；未读、失败、待复核分开显示。过长章节各子段全部完成，才算该章基础处理完成。
3. 阶段、人物、信息和因果关系可以追溯至实际读过的章段；重要转折与疑问有针对性回查。
4. 所有普通章节仍可检索；不只留下“精彩选段”，也研究过渡、休整、铺垫和关系积累。
5. 方法与表达方案有适用边界，并记录用于原创任务后的评价；无效或证据不足时补读/修订，不因卡片数量多就认定效果好。

不能承诺模型永久掌握全部书，或一次压缩后不丢信息。文件范围覆盖、分析证据有效、作者采用、实际改善是不同指标；“全部章已发送给模型”也不代表解释全部正确。部分系列或连载截点只研究现有范围，不补造未提供章节或作者意图。

## 3. 大文件处理：原书卷、存储分册、故事阶段分开

### 3.1 保留原件，生成可核对的派生文本

原件先以SHA256登记并复制到可恢复的私人语料归档，来源路径保留。EPUB保存原压缩包、spine顺序、目录和资源位置；TXT保存原始字节、声明/检测编码与异常区间。原件归档是新增语料功能，不把大文件硬塞进a9的10MiB来源接口。

派生文本记录解析器版本及每项变换。默认不改繁简、标点、段落或正文措辞。EPUB的HTML文本抽取、换行统一、脚注和重复内容隔离都必须可追溯：TXT关联原字节区间，EPUB关联包内资源及节点/文本锚点，再映射到规范文本Unicode码点半开区间。不能把EPUB压缩文件偏移直接当正文位置。

候选整理需要展示原顺序与新顺序、重复依据、异常位置和未确认项。编码不确定或正文被切断的范围可先隔离；其他已核对部分可处理，但必须保留未覆盖缺口，不能标整书完成。保真文本修订产生新版本，引用不能静默改指新文本。

### 3.2 拆分规则

- **原书卷**：有可信卷目录则保留；无卷不强行发明“作者原卷”。目录与正文不一致时保留差异。
- **存储分册**：只为容量和批次处理而切分，标明“技术分册”。优先在完整章之间切，目标每册UTF-8文本4–6MiB、拟议硬上限8MiB；按转换后的实际字节计算，不按原TXT大小或EPUB压缩体积估算。
- **超长单章**：在自然段/场景边界分子块，保留同一chapter_id、前后邻接和正文连续区间。用于理解的重叠上下文单列，不重复计入正文覆盖。
- **故事阶段**：由叙事目标、冲突与结果分析得到，可跨自然卷/技术分册；不能用文件边界冒充文学阶段边界。

重分册不改变同一文本版本的章节身份；重解析导致文本或章节边界变化时，生成新解析版本及显式映射，旧引用保留或标失效，不靠相同章名猜测迁移。

## 4. 多遍阅读：不止摘要，不只精彩片段

### 第一遍：全章基础覆盖

按已核对顺序阅读全部正文。每章保存章段及场景范围、目标与阻力、行动/选择、代价/结果、状态改变、未决问题、主支线作用，以及基础表达观察。字段允许不适用、未显式出现和待核，不要求填齐，不据模板反推不存在的目标、冲突或代价。变化不限于输赢或大事件，也包括关系、认知、资源、期待和情绪的细微积累；不把安静场景机械判成“无用”。

首轮保留当时读者能知道什么、各角色能知道什么、哪些只是猜测。记录每个实际发送区间；需要承接时取已完成前文和必要原句，不能把模型已有印象当本版本证据。场景边界和功能判断本身也可待核。

### 第二遍：故事阶段与四组结构地图

| 地图 | 分析重点 | 证据边界 |
|---|---|---|
| 内容安排/因果 | 阶段目标、限制、主支线进入退出、准备、转折、结果与后果；每章为后来提供什么条件；人物/段落对照及主题展开 | 原文先后、相关和因果分别标记；因果解释须有依据，主题允许多种解释，不直接推定作者意图 |
| 人物/关系 | 想要什么、知道什么、拥有什么、做了何种决定、关系为何改变、人物弧线如何形成 | 可观察表现与内心解释分开，人物状态均绑定时间与章节 |
| 信息/线索 | 读者与各角色首次获知、隐瞒/误解、再次提示、揭示及仍开放的问题 | 候选记录铺设及疑问，允许疑似、未兑现和不能确定；仅标记“已兑现”时要求铺设、兑现两端及连接解释 |
| 节奏/情绪 | 时间跨度、视角切换、冲突与恢复、期待与延迟、高潮前后安排、日常积累 | 曲线是有证据的分析视图，不是客观文学质量分数 |

重点阶段进行场景级细读，检查其引入、升级、转折、结果与后果是否均被理解。已拥有的其他章节保留基础结果，日后可按疑问升级为深读，不需重新处理整书。

### 第三遍：全书回看与原文复核

建立全书主支线、阶段、人物和信息地图后，主动回查关键准备、转折和兑现原文；不能只递归压缩逐章摘要。将“初读时的疑问”与“知道后文后的解释”并列，防止后见信息回填到早期角色。

大范围关系若只验证部分章段，就显示已验证端点与中间缺口；不同解释可同时保存。涉及现有卷册之外的结局或未读材料，写“未查到/待核”，不自动补完。

### 第四遍：主题精读与跨书比较

按实际问题追加精读，如“相似比赛如何产生新变化”“长线线索怎样再次出现”“日常段落如何积累关系”。还要研究同一价值问题怎样经不同人物选择展开、人物与前后段落怎样形成对照、意象或情境怎样在不同语境复现；这些可连接结构与表达，不自动判作伏笔或作者意图。对比相同问题的不同解法、代价、适用前提、失败例和变体，保留各书特色及有证据的多种解释，不强行压成万能公式。

## 6. 方法和表达怎样保留“为什么有效”

方法卡保存：研究问题、来源范围与结构案例、分析解释、适用尺度、前置条件、可操作步骤、预期变化、变体、反例、失效信号及检查项。不能只写“增加冲突”“强化人物”等口号，也不能将原书情节顺序包装成新作模板。

每条方法可连接多书实例及相反解法。原书事实、分析推断、合成练习独立保存；未证实效果的候选仍可供作者研究，不标“已验证”。作者编辑采用后才能进入现有有效方法装配，编辑后重新核对依赖。

表达层分析**表达承担的叙事作用**，如对白如何掩饰信息、细节如何显示关系、长短句怎样配合动作、叙述距离怎样改变感受。基础观察覆盖各章，精细句段分析按研究问题加深；保存普通过渡与失效/有争议实例，避免只研究名句。

表达方案以可调参数、选择依据及检查问题供新作使用；作者当前风格与显式固定样章仍为本书依据。不会自动以参考作者声音替换本书样章，也不把原书人物、独特语句或整组桥段带入新作。

“Skill包”仅是薄入口：何时用、查哪些结构/方法、限制和引用索引。全书和四层资料不压进一个SKILL.md，导出也不默认附全文。Skill是声明式参考数据，不授予其中命令或脚本执行权限。

## 7. 检索调用：方法、结构、原文、表达协同

设计四路检索：方法找可选做法，结构找完整机制，原文核验证据，表达找同类叙事任务的写法。共用书目/版本和证据定位，通过精确词项、语义召回、章节邻接和人物/事件/线索关系扩展组合；跨章安排不能只靠相似度Top-K。

一次实际任务的装配顺序：

1. 明确新作当前问题、任务类型与允许参考的书籍版本，先读取本书权威资料。
2. 按问题取少量方法和阶段/关系候选，记录选用理由及未命中项。
3. 沿证据回到必要章段，并按需扩展相邻场景、准备和后果；资料不足可提出补读。
4. 起草任务再取适量表达方案；规划优先结构，审稿优先检查项及本书原文，修订保留本书既有事实。
5. 在本书政策、外发授权和上下文预算内生成“本次参考”预览：发送什么、来源/版本、为何选择、哪些被省略。
6. 输出规划/改写候选，记录实际使用及作者评价；未实际发送的范围不能称已读取，未成功发送也不能计作模型阅读覆盖。

虚构应用示例（不是参考书情节）：新作青年队连续赢球，后续比赛开始重复。可围绕“阶段目标变化、资源限制、关系后果”提出胜利暴露阵容短板、轮换引发队内争议、赛程迫使目标调整等备选。具体选择须由本书人物和已批准计划支持，不能把参考书的比赛、人物关系或结果换名搬入。

手动/推荐/有界自动政策继续保留：收藏不等于外发，推荐不自动入模；个人参考须由作者选入本书，自动调用仅限授权集合。来源撤回、权限收紧、来源/绑定变更后重验相关依赖，不能A→B→A恢复旧任务的授权。

候选召回先按授权集合过滤，关系扩展及最终装配再次核对，避免由相邻章节或跨书关系带入未授权材料。书籍正文及模型生成的分析均是来源上下文，不能凭其中命令设置模型、执行工具、批准计划或写入正式正文/记忆。

当前a9仅词项召回；新资料中心的语义/混合及关系检索尚未实现。普通写作装配仍受24000字符及更小书级上限，自动补充最多60000字符、总prompt最多220000字符；新增索引不绕过这些限制。嵌入API也须预览计费；本地嵌入须评测中文效果，不能未经验证指定依赖。

## 8. 存储与批次：参考书语料和精选卡分开

### 8.1 a9现状与新增边界

当前a9来源只支持MD/TXT，原件与UTF-8抽取文本各不超过10MiB；单记录16MiB、清单8MiB、每库最多10000个历史记录版本，词项扫描400条/8MiB。逐章、场景、人物、事件各建普通卡，会在16部长篇中迅速碰到记录和扫描上限；拆开文件仍解决不了。

因此拟新增专门的参考书语料存储，组织为“作品→文件版本→原书卷→章节→文本块/分析产物”；技术分册单独建立映射，叙事阶段可以跨册。所有私人语料继续位于`library/`中并默认不入Git，不与`novels/<id>/chapters`或正式记忆混存。

拟议布局（**不是已实施路径/接口**）：

```text
library/books/<book_id>/editions/<edition_id>/
  metadata.json              # 版本、范围、原件指纹及整理决策
  originals/                 # 原始字节归档
  text/                      # 分册、卷章/块定位、异常与变换映射
  analyses/<run_id>/         # 逐章、阶段、关系、方法及表达候选
  batches/<batch_id>/        # 依赖、覆盖、预算及恢复状态
library/indexes/             # 可重建词项/语义/关系索引
```

章节/块与细粒度关系保存在可分页的版本化产物中，不全量铺成普通entry；选出的技法、方法、表达观察通过有类型的book-evidence引用接入现有卡与本书绑定。索引是派生物；文本与分析产物是权威记录，不能把唯一证据只存在向量库。

新语料合同建议首版原件每份≤128MiB，EPUB解包资源合计≤256MiB，规范正文每版本≤128MiB；技术分册硬上限8MiB、每版本最多20000章。目录和分析索引分片/分页，单清单仍≤8MiB；整库磁盘配额在导入预览中显式配置，超出时拒绝或选择范围，不静默截断。这些是待实测的设计上限，不修改当前a9限制；实施须用16份材料验证内存、大小和引用映射后写入新版存储合同。

兼容策略：旧a9资料、来源和引用不自动迁移/重写；新语料引用增加明确类型，旧客户端不能将其误当旧source_id。引用包含book/edition、解析版本、chapter/block、Unicode范围和原文hash；分析另固定run及提示/模型版本。相同hash不替代单调版本与授权状态。建立新数据恢复、清除及撤回合同后，才开放批量导入。

新book-evidence必须进入任务快照的typed_deps，绑定语料/解析/分析版本及授权epoch；实际发送、迟到结果发布和恢复时全部复验。现行expected_library_hash只覆盖a9库清单，不能独自证明拟议books/语料未变或仍获授权；新版接口需显式增加语料依赖门禁，不用旧hash冒充完整校验。

### 8.2 批次任务图和预算

任务图包含预检→分章→逐章分析→阶段归并→跨章验证→全书归并→主题/跨书分析→方法/表达候选→评阅。归并节点只能消费已完成且版本有效的前置产物；独立章段可并行，但跨章判断须等待必要上下文，不能为吞吐量牺牲知情顺序。

整批冻结来源及解析版本、精确范围、提示/模型/参数、外发授权和预算快照。按节点持久化状态与实发范围；暂停阻止新节点，进行中的付费请求仍需落账。成功结果复用，失败节点显式处理，状态不明请求先对账，重启不自动重放。来源变更仅使相关后继过期，保留可核查历史，不无差别重读全书。

预算预览必须含初读、承接/重叠、阶段/全书归并、原文回查、方法提炼、跨书比较、独立评阅、嵌入及允许重试的总量，显示已消耗、预留和剩余。规范文本确定后，使用可用分词器计数或保守估计并标明口径；归并、回查和未知输出设置上界与预留，预估不等于实际账单。价格缺失标未知，不在设计阶段编造16本的固定总价。跨批共享总预算，超限停止，不因拆任务绕开上限。

首版沿用明确所选计费作品账本，整批预览显示真实承担费用的作品；**不能默用awl，不读取计费作品正文作为研究输入**。若后续增加独立个人研究账本，须设计新账户类型、配置及迁移，不伪造小说项目承接费用。保存书目、建立目录或本地索引不自动触发模型请求。

完整备份须包含原始文件、派生文本、映射、分析产物、批次/预算及被绑定的私人卡；索引可重建。恢复后保持付费请求状态与授权，不将“恢复”当作自动重跑。之前的`reference-preflight-20261020-after.zip`仅备份库与预检记录，不含D:/下载原件，不能称作本批全本备份。

## 9. Studio入口与作者操作

“资料中心”增加**参考书架**；不将参考小说创建成正在创作的作品。书籍详情提供以下入口，正文和证据始终可以打开：

- **原文与目录**：原卷/技术分册、整理前后对照、附记与异常、缺口、版本。
- **全书结构**：章节/阶段地图及人物、信息、因果、节奏等视图，可回查两端证据。
- **方法与表达**：按创作问题组织，查看边界、实例、反例、候选/采用与试用状态。
- **覆盖与任务**：未读/已处理/待核矩阵、批次暂停/恢复、实发范围与总预算。
- **跨书研究与使用记录**：同问题多书对比、本书实际调用理由和作者评价。

三个研究入口并列：按问题读、沿人物/事件/线索追踪、跨书比较。仅提供一个检索框容易把长篇割碎；仅提供全书摘要又会丢失机制。图谱作为可回查的分析视图，不以节点数量代表文学理解。

写作页面增加“本次参考”面板，显示取用的结构/方法/表达和必要原文；推荐不等于采用，作者可排除不合适参考。不把内部ID、解析器设置等默认塞进创作表单，需追溯时才展开。

## 11. 验收：完整性、可信性与使用效果分开

| 维度 | 必须检查 | 不能据此声称 |
|---|---|---|
| 文件与解析 | 原件指纹不变；所有正文区间有去向；异常/重复/附记可核对；重分册引用稳定；全本备份恢复 | 文件可读即发行版无缺章、部分卷册即系列全集 |
| 阅读与分析 | 解析、实发、结构/表达分析、复核分别计数；章/正文范围覆盖双维度；冲突和未读明确 | 完成率100%即模型理解100% |
| 关系与归并 | 两端可回查；推断与原文区分；初读与回看分开；来源变化使相关结论过期 | 有图即因果成立、重现即伏笔回收 |
| 检索与政策 | 中文任务样本含普通章、跨卷线索、精确名称和无命中；来源隔离、预算、撤回和版本校验 | 一次召回即读过全书或能保证正确迁移 |
| 任务恢复 | 各发布/计费边界中断、结果不明、依赖变更；不发半套、不自动重复付费 | 已有单库journal即完成跨库/正文原子事务 |
| 作者使用 | 匹配模型/任务条件与明确成本，比较无资料、仅摘要、四层参考；作者匿名评阅并记录修改/弃用理由 | 方法已采用或引用通过即文学效果有效 |

统计应给出分母和缺口：例如已解析正文、已成功发送正文、已完成结构分析章节、已深读阶段、已验证关系、已试用方法。未知/未检测与零问题分开，叙事标签不生成伪精确质量总分。对照任务仅产候选，写章与定稿继续遵循本书审批边界。

## 12. 是否需要训练

当前优先采用四层资料、检索及方法装配，不需要先训练。RAG补充本次上下文，方法/Skill补充任务步骤；两者都不让模型永久学会全书。单纯以原书续写训练，也不直接等于学会跨百万字规划、审稿与内容安排。

若后续留出评测仍存在稳定缺口，再单独评估SFT/LoRA或偏好优化。优先积累作者确认的“要求→规划”“原稿+问题→修改”“候选比较→偏好/理由”，分别验证泛化、记忆复现和成本；服务商是否支持训练、可用权重及训练资料范围另行确定。训练不是本轮资料利用的前置，也不是“完全吸收”的保证。

## 13. a10已实施范围与后续出口

入口为「辅助工具 → 资料中心 → 参考书架」。它与a9普通卡片库分开保存，支持EPUB/TXT/MD原件、不可变解析版本、分页目录/原文、精确词项检索、异常/重复候选、指纹核验、外发政策和研究批次。解析器`reference-books-v3`增加对本批实际存在的“正文 第N章”标题的保真识别；旧解析版本保留，不静默迁移已有引用。

批次先预览并冻结所选版本/范围、真实计费作品、planner模型、价格、Token和整批美元上界，再保存为prepared，作者明确启动才发请求。章段上限50000个Unicode字符，过长资源沿自然段连续拆分；所有子段成功才计该章完成。归并每组最多4个前置候选，包含其结构、表达、线索、方法与缺口；完整逐章结果另外保留，不靠最终摘要替代。短生命周期批量核验减少千章重复哈希，发送前和返回后仍各自重新核验原文、授权和配置。

每条证据需逐字对应实发区间；“已回收”线索同时要求铺设和兑现两端。归并会回验原文传递依赖，但没有重新向模型发送所有原文，也没有连续维护前文读者/角色知情状态。因此这是**独立章段观察＋层级候选归并**，尚不等于第4节设想的多遍连续精读、独立验证的全书地图或跨书比较。超出输入、候选或预算限制时明确失败并保留已有记录，不静默截断、不自动重调。

当前文件异常的处理为保留并标注：剑来30处解码缺口、超能名帅1个NUL、冠军之心重复候选及疑似前置倒序结尾；不假装已经修复版本。黑暗森林目前按3个资源/区段保存，其中超长区段可技术拆分，尚未恢复自然章目录。缺口/控制字符所在范围拒绝自动研究，其他正常范围可显式选择；原件只作证据，不能获得代理权限。

L3-A的原件/派生文本/分册/恢复基础及L3-B工程骨架已落地。剩余包括：异常修订与新旧版映射的作者操作界面、自然目录深入核对、完整阶段与信息地图、针对疑问的再次精读、跨书研究、四层混合检索、研究候选到a9方法采用/创作装配的显式桥接、留出任务与作者效果评阅。未启动模型训练，不宣称“完整吸收”。实际测试、运行与备份记录见`reference_corpus_implementation_audit_v3.md`。

## 14. a11研究方法的实际使用

作者继续授权后，已实现第13节原列后续的“研究候选→a9方法采用→本书装配”桥接。成功节点或最终归并的方法可预览并保存为个人未采用候选；作者回查固定原文、编辑采用、明确外发与本书固定选用后，原有任务取材政策可装配方法文本。

此操作不重新调用模型，也不代替作者采用。研究origin只读封存并贯穿编辑、采用、绑定、任务及恢复；来源撤回再恢复、原件/前置结果篡改使旧使用失效。完整依赖按批次指针回验、仅保留有界摘要，不能把未发送的研究原句标为任务实读。失效卡可保留原内容并归档、撤回或收紧外发，但不能放宽或恢复采用。

语义/关系混合RAG、完整连续阅读与结构图、跨书研究及方法效果试评仍未交付。当前桥接只处理已经实际生成的研究，不会凭书名生成候选；真实16书未启动付费精读。接口、容量与验收详见`reference_method_bridge_v3.md`。
