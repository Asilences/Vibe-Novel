## 分析与费用边界

预览读取作者选定的精确范围，冻结来源版本、授权epoch、计费作品、planner主模型、价格和节点预算；空chapter_ids明确表示全书全部资源，含附记与重复候选。有缺口/控制字符则拒绝相关范围，不悄悄跳过。每个章段最多50000个Unicode字符，过长章连续切分；各子段全部成功才计该章完成。批次先保存prepared，点击开始才发请求。

父工程预留全DAG的费用、调用数和Token；各节点又受既有作品预算账本约束。未知费用按保守预留保留，不更换模型或自动重试；暂停只阻止后续节点，取消阻止迟到发布。重启不会重放请求。响应最多保留1MiB，标准候选最多12000字符，单引文最多240字符；无效/超限保留已有记录并失败，不截断原文或静默丢候选字段。

归并包含前置候选的结构、表达、线索、方法及缺口，逐层最多4个前置结果；原始逐章结果独立保留。发送与发布各建新的短生命周期校验作用域，批量验证原件、分册、定位、权限与传递原文依赖。对研究计划篡改、跨书结果路径、来源撤回再恢复及模型漂移均拒绝。逐字引文检查证明位置匹配，不能证明解释、因果或文学效果成立。
