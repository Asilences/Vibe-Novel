## 外部大纲与已有正文的验收边界

外部大纲可为散文总纲、只有卷纲、事件要点、断号/重号章节、缺人物时间线或不规则混合文本；导入不要求与 Studio 的规划 JSON 同结构。原文、原章号及不确定信息保留，规划候选的结构化转换是独立步骤，新增建议不能伪装成来源事实。

已有正文有两条不同路线：

1. 独立修订：导入原稿 → 校正分章 → 创建独立修订副本 → 本地检查或 API 审稿/改写 → 审阅差异 → 接受到本章副本 → 独立导出。原件和正式章节保留。
2. 继续创作：逐章核对导入稿并提出正式章节提案 → 分别批准和应用 → 按正式证据更新记忆提案 → 下一章规划及章计划审批 → 写前包 → 起草。已有稿页现有“修订与续写指南”和当前章编辑器入口；尚无批量接续或自动正式化向导，仍须逐文件审批。
