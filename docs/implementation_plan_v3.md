## 工程决定

1. v2 根目录保留；新作品存于 `novels/<novel_id>/`，不自动迁移旧资料。
2. 版本化 Markdown/JSON 为权威源，SQLite 后续仅做可重建索引。M0 无第三方运行依赖，Python 3.9+；配置采用 JSON，YAML 不是首批必需项。
3. 正式内容指纹是内容哈希，不是作者批准，也不是具有历史链的 revision。Studio 的单调 revision、历史快照与审批基线另行记录，不能用当前指纹替代批准记录。
4. 原件导入在一个目录内保存原始字节、抽取文本和来源 metadata；同盘暂存完成后发布整个目录。相同原件重复导入复用；不自动生成 canon 或批准纲。
5. 默认保留逐章计划审批。Studio 提供提案批准与单文件应用；不把按钮视为人类身份认证，不提前开放跨章节/记忆的批量原子定稿。
6. Studio 使用 React + TypeScript 与可选 FastAPI 依赖；CLI 核心保持标准库可运行。网页先行，Windows 桌面封装下一阶段。Markdown/JSON 权威源不因关闭网页或切换执行方式而改变。
