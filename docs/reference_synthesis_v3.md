# 连续精读后的阶段与全书归并

归并入口在资料中心的“精读与结构图”研究详情底部。当前选定范围的连续精读全部成功后，可设置每阶段30–50个阅读段、本批美元上限及输出Token，预览后保存为prepared，再明确启动。只有已读完整本机选定文件，才能将该范围称为当前文件全书；出版完整性仍以来源核验为准。

每个基础阶段收到全部阅读摘要、每类最多3条原观察及其精确引文，省略清单明确保存。各阶段按最多4路依赖归并，直至最终范围归并；1091个阅读段、每组30段产生37个阶段和14个分层节点，共51次候选请求。摘要归并不是再次发送原文，也不声称重新全书精读。原连续阅读检查点、四组候选结构图、原观察和引文全部保留。

每个结果分别包含阶段转折、主辅线、人物弧光、内容组织、独立表达观察、可迁移方法及证据缺口。所有条目精确引用实际收到的证据；短引文不能证明整场景效果或方法普遍有效。回顾分析不回填初读角色知情，不写作者作品事实。

`library/syntheses/<id>/`保存冻结计划及模板hash、阶段输入、实际请求、原响应、成功结果、离线修复、孤立写入归档和CAS进度。研究整体与每个阅读结果hash、书籍解析版、授权epoch均封存，发送及发布前重验。执行器持跨进程租约；未知/失败请求不自动重发，成功响应可沿同一私人研究账户缓存核对。原响应有保存时，可离线修复JSON或精确证据，保留原响应与费用。

精读与归并使用同一个`ResearchGateway`和累计私人研究账户。本批预览不增加总额度；达到累计上限或未知费用占用后停止新请求。后续层以有界最坏输入预留，实际请求不得超过预览费用、模型容量及本批总额。预览和保存不调用模型。

最终方法可由作者显式预览并保存到个人库，保留不可洗掉的`reference_synthesis`来源；仍未采用，不自动绑定小说。采用、编辑、本书绑定和发送继续重验全部研究及原文依赖。四层检索重建时，归并的阶段/人物/内容组织进入结构层、表达观察进入表达层；方法层仍只索引作者已采用的方法。检索结果须明确选用后才能进入写作任务。

完整备份须包含整个私人library、研究账户及对应作品运行预算；不只备份最终JSON。归并数据默认不入Git。
