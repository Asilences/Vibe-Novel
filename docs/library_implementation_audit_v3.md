2026-10-19。作者授权实施后，交付L1资料基础、L2-A分析/提炼及L2-B编辑/采用/按策略使用。功能与保留项见实施计划、资料中心设计第14节和方法吸收设计第10节；现行路径与身份合同以存储合同a9补充为准。

## 修复与边界

- 实发出处与依赖分开：只有实际发送的原句进入source_fragments；卡片仅绑定但没有发送的原文另列说明，不冒充模型已读证据。
- 普通标题/笔记更新不废固定来源旧版；外发授权和撤回独立推进epoch，防止收紧后再恢复使旧任务复活。方法编辑后重新采用。
- 分析精确身份在候选包发布及journal恢复时、同库锁内检查；归档或撤回后阻断迟到提炼，保留可核对的发布意图。
- 原件和UTF-8抽取分别检查大小；中文编码转换后超限在发布前拒绝。检索按实际编码大小计入预算；自动无命中允许正常任务继续，可选超限记遗漏，必选超限拒绝。
- 预览与提交冻结完整模型配置和资料hash；普通任务支持合法幂等键，重试共原预算，方法两阶段共原预算组。服务重启不自动重发状态不明的付费请求。
- 页面不递归展开内部依赖树；默认呈现资料名称、是否发送与理由，实际补充文本可展开。方法候选与原书案例/合成练习分别展示。

资料和文稿仍属不同存储锁域。普通候选发布前校验库，但没有跨库/文稿共同原子提交；已发布候选不会随资料撤回而自动撤销。后继工作流沿原任务复验，单文件提案及人工打开候选尚无统一库依赖门禁。这是明确保留项，不以本轮单库journal覆盖M2事务范围。
