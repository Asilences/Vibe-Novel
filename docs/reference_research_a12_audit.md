## 已实施的软件

| 范围 | 交付与核验边界 |
|---|---|
| 连续阅读与完整结构图 | 按来源顺序持久保存每段、原始响应、完整知情增量与前检查点指纹；下一段接收明确有界的笔记、实体和旧证据。因果、人物/关系/知情、线索、情绪/节奏四图可分页、按阅读时点过滤、回查原文和保存人工编辑版。图和评分均为候选。 |
| 主动补读 | 从节点证据定位精确区间，新建回顾研究；不能把后读信息回填为早先角色或读者知识。 |
| 跨书比较 | 同一问题逐书解法、前提、差异、反例与跨书方法；所有选中书籍须有独立精确引文，跨书观察与方法须至少两书证据。一次最多每书 24000、合计 48000 字符，不冒充全文比较。 |
| 方法库桥接 | 已成功研究结果可发布个人库候选，来源固定到全部书籍、版本、检查点与证据。作者采用、本书绑定、任务选入分别执行，编辑清采用；任一来源撤回或篡改均使旧装配失效。 |
| 四层混合检索 | 本地 BGE 512 维语义、中文词项及有证据图邻接；原文、结构、表达、已采用方法分别索引。完整范围分页构建，来源和政策变化失效。勾选并预览后才固定到本书下一次任务，构思、规划、编辑、修订与多模型入口均携带同一选择。旧任务不能清掉后来选材。 |
| 目录与异常整理 | 精确文本补丁、拆分、合并、排序、隔离、派生版发布/切换、直接父子范围映射。每个可读码点有明确去向，原件与旧版保留，未知坏字不得猜补。 |
| 方法效果与文学试验 | 同一原创简报，比较无参考、方法摘要、结构化方法与证据三条件；另发一次匿名 AI 评阅请求。作者盲评单独保存、首次评价后揭示条件；代理未代投。单次同模型试验不能证明方法因果效果。 |
| 独立研究预算 | 精读、比较、效果试验共享私人账本，不借用作者作品计费。精确提示、模型、协议选项、价格与上限冻结，发送前预留；未知费用占用额度，不自动重放。 |

入口：`资料中心 → 精读与结构图 / 语义检索 / 方法效果评阅 / 研究预算`；目录整理在参考书架单书工具中。
