# Studio 作者流程与交互审计

更新：2026-10-21。范围：3.0.0a12、作者流程入口修复及后续真实 API 验收中发现的交互缺口。本文区分源码确认、自动检查和实际浏览器验收；未执行的场景不记作通过。[2026-10-20 作者界面验收报告](studio_author_ui_acceptance_20261020.md)及下文第3、4节保留该批历史证据。2026-10-21 新增问题见 UX-24 至 UX-33；真实付费路线的完成情况须另按本轮记录核定，不能由旧离线结果推断。

## 1. 本轮验收目标与边界

作者反馈：单 API 弹窗找不到输入/输出价格；逐章研究看不到开始按钮；大纲生成后不知道在哪里创建规划包。后续实际使用又发现创建规划包按钮重复，以及“本次资料与方法”只有展示、没有选材操作，输入参考书名与真实资料读取的关系不清楚。将这些反馈扩展为一次按作者创作流程的入口、前置条件、按钮、跳转、结果反馈及错误恢复检查。

2026-10-20 的写入测试使用隔离作品、合成资料和离线假模型，真实作品只作必要的只读核对。2026-10-21 作者另行授权独立 5 美元上限的真实 API 功能测试；续测仍在隔离作品中完成，费用、已发送请求与未知状态共用该批账本，不能将此前参考书研究预算当成可追加额度。测试不更改原作的正文、记忆或作者批准状态，不自动扩大原作或参考资料的外发权限。作者盲评可测试协议，不能代作者给真实文学效果投票。

### 规划现场选材专项

- “为本次任务选择资料与方法”列出当前作品卡片和作者已固定用于本书的个人版本，不扫描其他作品。每项说明本书/绑定、外发政策及版本；不合权限/采用/用途条件的项禁选并说明原因。
- “从参考书检索选段”在弹窗内复用已有索引，勾选→预览精确文本→“将所选片段加入当前任务”；选择保留卡片、来源范围和查询，替换旧检索选择。弹窗关闭前保护未应用勾选。
- 没有索引时明确给出到资料中心建立的下一步；本轮接线应核对跳转入口实际渲染，不能只有可选回调而调用方未传入。
- 手动勾选与已保存的自动政策可以共存，手册明确自动策略仍可能补充资料。最终预览不能把研究引用依赖冒充已发送原句，不能把提到书名冒充已读该本地版本。
- 验收主参考《足球豪门》的内容安排和辅助通用表达时，应选具体证据片段/已采用方法卡，并在实际补充文本中查到；若该书尚无结构层研究或可用方法，不以书名声称已有。原文研究范围、采用状态、图层覆盖与本次真正使用各自显示。

- 外部大纲没有统一格式前提。散文总纲、仅卷纲、情节要点、跳号/重号/番外、缺人物或时间线、不规则 TXT/Markdown/表格/缩进均可作为原始材料；接受导入不等于成功理解、补齐或批准其结构。原件保留；原章号与本批新章计划的对应、缺失信息和新增建议仍须作者核对，当前没有通用外部章号映射编辑器。
- 普通助手选材与规划选材使用相同资料校验，但各任务用途分别限制。参考书只有导入、尚未建可用索引时，先到“资料中心 → 语义检索”预览范围并建立索引，再返回助手选段；不能把内嵌选择窗口当成首次建索引入口。关闭语义召回也不代表扫描未索引的整书。
- 普通审稿／改写的高亮文字须另点“使用当前选区”才能作为任务范围。失效选区不自动降为全文；正文修改后先保存，再重选或明确整章。最终确认读取冻结 request，不能根据后方仍可编辑的表单推断；来源版本、范围、目标或强度变动均要求重预览。选区改写发布完整候选时保留选区外原文，不能由此自动定稿。
- 已有稿续写需要经过多个工作区：本轮在修订会话中补充“独立修订”和可折叠的“继续写作”指引，列出逐章打开编辑器、核对正式章号、提案批准应用、补核正式记忆、下一章计划与写前包起草的步骤，并提供当前章节编辑器按钮。指引不批量纳入正式或自动续写。副本编号只对应本次切分顺序，目标章号须手工核对；记忆缺失会列为写前包缺项，不会自动补齐或强制阻止起草。使用手册已补具体两章导入后写第三章的路线；源码与离线检查不能充当真实续写已验的记录。
- 目录合并后拆分使用某个原始来源段的码点坐标，不使用合并文本重新累计的坐标。先生成草案，再预览、保存候选、明确发布派生版，原件、旧版及直接父子映射均保留；未知坏字不得猜补。
