# Studio 作者流程与交互审计

日期：2026-10-20。范围：3.0.0a12 及本轮入口修复。本文区分源码确认、自动检查和实际浏览器验收；未执行的场景不记作通过。

## 1. 本轮验收目标与边界

作者反馈：单 API 弹窗找不到输入/输出价格；逐章研究看不到开始按钮；大纲生成后不知道在哪里创建规划包。后续实际使用又发现创建规划包按钮重复，以及“本次资料与方法”只有展示、没有选材操作，输入参考书名与真实资料读取的关系不清楚。将这些反馈扩展为一次按作者创作流程的入口、前置条件、按钮、跳转、结果反馈及错误恢复检查。

所有写入测试应使用隔离作品、合成资料和离线假模型。真实作品只作必要的只读状态核对，不保存真实 API 报价、不更改原稿、预算、外发授权或作者批准状态；不把本轮软件验收视为新的付费研究授权。作者盲评可测试协议，不能代作者给真实文学效果投票。

### 规划现场选材专项

- “为本次任务选择资料与方法”列出当前作品卡片和作者已固定用于本书的个人版本，不扫描其他作品。每项说明本书/绑定、外发政策及版本；不合权限/采用/用途条件的项禁选并说明原因。
- “从参考书检索选段”在弹窗内复用已有索引，勾选→预览精确文本→“将所选片段加入当前任务”；选择保留卡片、来源范围和查询，替换旧检索选择。弹窗关闭前保护未应用勾选。
- 没有索引时明确给出到资料中心建立的下一步；本轮接线应核对跳转入口实际渲染，不能只有可选回调而调用方未传入。
- 手动勾选与已保存的自动政策可以共存，手册明确自动策略仍可能补充资料。最终预览不能把研究引用依赖冒充已发送原句，不能把提到书名冒充已读该本地版本。
- 验收主参考《足球豪门》的内容安排和辅助通用表达时，应选具体证据片段/已采用方法卡，并在实际补充文本中查到；若该书尚无结构层研究或可用方法，不以书名声称已有。原文研究范围、采用状态、图层覆盖与本次真正使用各自显示。
