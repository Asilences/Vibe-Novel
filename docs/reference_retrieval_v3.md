# 参考书四层本地混合检索（a12）

本模块将原文、内容结构、表达和作者已采用方法接入同一检索界面。检索过程不调用付费 API，不训练模型，不把相似度或图关系当作本书事实。

## 检索与使用流程

1. 在资料中心的混合检索界面明确勾选书籍和资料层，预览本次当前文件版本、解析章段与字符规模。
2. 确认后在后台建立本地索引；可取消，只有完整成功发布的索引允许检索。重启不会自动续建或发送 API 请求。
3. 输入研究问题，使用中文词项、真实本地中文 BGE 向量及已有图谱证据关系混合召回。
4. 查看每条结果的资料层、实际文本、来源范围和分通道排序，必要时回查固定版本原文。
5. 明确选中片段，再预览外发资料包。只有作者允许外发的来源及已采用方法可通过；仅本地书籍依然可以建索引和在本机检索。
6. 点击用于本书下一次任务，后续任务继续预览模型、预算和冻结资料版本。检索本身、手动选中和预览均不启动模型任务。

## 四层实际来源

| 层 | 来源与边界 |
| --- | --- |
| 原文 | 当前解析版精确 Unicode 区间。全选索引包含当前文件可解析的正文、封面等附属资源；标题保留其区段身份。异常章段整章不索引并列出遗漏。 |
| 内容结构 | a10 成功章节/归并观察，新连续研究的事件、人物、知情、线索、跨书比较结果，以及经过证据核验的图谱节点。 |
| 表达 | a10 成功表达观察，新连续研究的节拍、情绪、张力候选及节奏图。数值是研究判断，不是客观文学质量。 |
| 方法 | 个人库中作者已经采用、未撤回、未归档且来源仍有效的方法。AI 候选和未采用方法不进入此层。跨书方法的全部依赖书须在本次索引选集中。 |

无成功研究时结构与表达层显示 0；无作者采用的方法时方法层显示 0。选中四层不表示每层已经有内容。新增研究或方法之后需显式重建索引，不会静默替换旧索引范围。

失败、暂停或运行中的研究若已有成功前缀，也可通过 `export_verified` 核验后收录。索引保留实际已读/总片段数，前缀之后的空缺不会跳过或补填；继续研究会使旧快照失效，需显式重建。

## 算法与计分

- 本地模型复用 `core.semantic.engine_for`：`Xenova/bge-small-zh-v1.5` 固定 revision、校验 SHA256 的量化 ONNX，512 维单位向量。没有随机/占位向量或远程 embedding 替代。
- 原文和分析按最多 240 个 Unicode 字符分块，步长 200；以适配已有本地隔离语义工作进程的输入边界。原文不改变，重叠片段的索引字符合计不等于原文件字符数。
- 中文单字、双字及英文词写入 SQLite FTS5；BM25 只用于词项通道排序。
- 向量通道采用余弦相似度。词项与语义各取前 200 个候选，以 RRF（k=60，权重各 1）合并。
- 关系通道只沿成功研究导出中有原文证据的实际图边扩展，权重 0.5；同一研究条目可链接其实际存在的图节点。没有图谱就返回 0，不根据相同人物名或相似词虚构关系。
- 分数与各通道排名均展示，不设“文学正确”阈值；低分和标题页等候选仍可能不适合当前任务，须由作者筛选。

## 存储、限额与失效

派生索引独立位于被 Git 忽略的 `library/.retrieval/<index_id>/`，含 `manifest.json`、`cache.sqlite3` 和写入锁；构建临时文件为 `building.sqlite3`。它不写入正式章节、记忆或作品设定，也不修改参考书政策。

- 单索引最多 10 万片段、512 MiB；所有本地检索缓存合计上限 2 GiB。超过时构建失败，不发布截断索引。旧索引需归档整理，不自动删除。
- 最多一次显式选择 16 本书，原文规模过大时须分书建立；检索只覆盖当前选定索引，其他书不会被默认扫描。
- 任务补充包最多 24,000 字符（含包装），最多 30 个片段，封存依赖最多 256 KiB；与其他卡片一起使用时仍受本次任务总补充预算限制。
- 原文、研究、采用方法各自保留固定版本、哈希及授权时期。外发权限收紧、撤回再恢复（A→B→A）、解析版本变化、研究图谱修改、方法编辑或取消采用都会使旧依赖失效。
- 查询返回的原文/分析重新从权威来源构造，SQLite 中的引文不是权威来源；向量缓存指纹或原文被改动时拒绝返回。
- 任务通过 `library_selection.retrieval_selection={index_id,ids,expected_preview}` 显式绑定；发送前、完成和恢复阶段沿 `reference_retrieval` 类型依赖重新核对。检索附带的证据列表不自动计为后续模型实读原文。
- 备份私人资料时应包含整个 `library/`；SQLite 是可重建的缓存，但已准备任务还依赖其精确选择与私有研究来源。备份研究还须保留真实计费作品的路由与预算账本。

## 已执行验证（2026-10-20）

专项测试覆盖本地查阅与外发分离、A→B→A 撤回、建索引期间来源撤回、缓存和引文篡改、方法采用撤销、精确任务依赖、CSRF/Origin/路径边界，以及旧研究兼容、连续图谱扩展与跨书比较索引。测试中的向量是明确标示的离线 fixture，不用于生产。

真实本地模型另行验证了《活着》当前文件的全范围索引：94,683 个原文字符、477 个重叠片段。用“失去家人之后，老人如何继续平凡的生活”检索，召回丧妻回忆、平常生活回望等实际原文，展示了中文改述问题的真实语义通道排名。私人结果保存在 `library/catalogs/reference-retrieval-pilot-20261020.json`，不入 Git。该验证不等于完整文学评估或宣称其他 15 本已建索引。

后续试点完成后可将其成功研究、跨书比较与作者已采用方法重建进同一索引；实际覆盖以索引清单为准。
