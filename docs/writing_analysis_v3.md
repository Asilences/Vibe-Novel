# 写作检查与 API 工作流集成（3.0.0a4）

日期：2026-10-19。本轮按作者要求吸收 dsh-novel-writer 的适用能力，并删除 Codex 交互接力，提供模型与 API 设置界面。

## 审计决定

参考项目：[siweina/dsh-novel-writer](https://github.com/siweina/dsh-novel-writer/tree/0408091c6a189d965b55bbb22a156523cd3cb189)，审计版本 6.6.0 / `0408091`，MIT。借鉴写前包、固定作者样章、带位置的改稿清单、明确检查覆盖范围的设计。VibeNovel 自行实现 Python 标准库核心和 React 界面，本轮没有复制第三方源代码、捆绑模型/词库或启动其 MCP 服务。

原插件目录、自动写章/设定与资料移动工具不符合 NovelCore 的作者审批契约；直接接入还需独立 Node 运行环境。先实现原生分析能力，后续真正语义检索单独评估嵌入模型许可、中文检索效果、可重建索引及缓存失效，不把字面匹配称为语义检索。

## 已实现功能与边界

| 功能 | 行为 | 限制 |
| --- | --- | --- |
| 写前上下文包 | 有效已批准章计划、父规划、上一章、近期正文/摘要、实际状态/事件/伏笔/重复记录、设定与样章统计；可导出 | compact 60,000 / full 160,000 字符；必需章计划/父规划超限拒绝；其余缺失/截断明确记录 |
| 任务整合 | API 起草复用写前包核心，作者可选模式；来源 hash、正式 revision、样章配置绑定输出 | 生成时重建当前材料，不把曾预览过视为永久授权 |
| 固定样章 | 作者选 1–10 份本作品草稿/正文，保存文本快照与统计；原件变化提示失效 | 原文本总量 1 MiB；不自动全书替代；待检查稿本身是样章时跳过本次文风比较 |
| 本地审稿 | 套话、长句段、去标点空白后的相同段落、样章平均句长变化；行号、原句、优先提示与建议 | 单稿最多 200,000 字符、100 条提示；字面段落比对只覆盖 40–2,000 标准化字符的段落；不自动修正文 |
| 处理清单 | 待处理/已处理/忽略；报告版本及来源漂移检查 | “已处理”为作者标记，不能证明已修好；旧报告失效后不允许标记已处理，需重新分析 |
| 历史检索 | 中文二元字组与拉丁词项，正式章节原句、行号、hash | 最多80个文件、8 MiB；目录枚举最多1,000项，遗漏可见；没有语义一致性结论 |
| 模型设置 | DeepSeek/MiMo/GLM/豆包/自定义，模型ID可编辑，密钥输入及清除 | 预设为填写建议，模型权限以服务商为准；保存不请求模型；外部API需HTTPS |
| 执行方式 | 新任务仅API，缺省API；API无效规划JSON仍支持人工修复 | 旧Codex任务只读历史，不继续/重试/回填/恢复发布；未终结旧任务启动时标中断 |

写前包按章节时点选择正式资料，前章缺号不拿其他章节冒充。没有章号的记忆汇总在回写历史章、已存在当前/未来定稿时省略，避免误当过去状态。文件名的章号无法证明文件内部所有陈述的时点，仍须作者核对。父规划、关系和未来伏笔均标为策划；样章只提供统计，不把未来样章正文加入角色知识。

## 数据与接口

- `ChapterBriefStore` 返回包文本、分项来源、缺失/遗漏、预算和正式版本；`POST /api/projects/<id>/analysis/brief` 只装配，不审批或生成小说。
- `AnalysisStore` 样章位于 `.runtime/style-baseline.json`，与小说事实分离，但备份作品时应保留作者选择；`GET/PUT .../analysis/baseline` 使用配置文件 hash 乐观锁。
- 报告为 `reviews/analysis-<uuid>.json`，通过同一版本/事务核心保存。`POST .../analysis/reports` 创建报告，`GET .../analysis/report` 重算失效，`POST .../analysis/mark` 在锁内校验来源并记录处理状态；`GET .../analysis/search` 只读检索。
- 生成/报告发布在同一锁中检查正文、正式 revision 与固定样章配置；改变配置或依赖时拒绝旧输出。`config_hash` 是样章清单指纹，HTTP `expected_hash` 使用完整配置文件的 `hash`，两者不混用。
- `GET /api/settings` 仅返回非密钥字段、是否配置密钥、环境覆盖字段名与预设；`PUT /api/settings` 受本机同源/请求令牌保护，版本匹配后原子写入固定配置文件。空密钥保留、显式清除才删除；更换接口地址须提供新密钥或清除，避免把旧密钥发给新服务商。
- 密钥输入只保存在页面内存，提交后清空；不进入浏览器持久存储、URL、任务或日志，不返回已保存密钥片段。环境变量仍逐字段优先，设置页明确提示被覆盖的字段，不显示覆盖值。

## 后续阶段

本轮为写作辅助模块，不代表 M2 多文件原子定稿完成。人物出场/知识、伏笔回收、赛事积分和合同等领域事实检查仍需结构化记忆及定稿证据。真正本地语义检索、交互式关系图与完整审稿语义判断维持在后续计划中。

验收结果在 `implementation_plan_v3.md` 记录；仅使用临时作品、假模型和本机 HTTP 协议测试，不以离线测试宣称厂商模型准确率或真实作品文学质量。
