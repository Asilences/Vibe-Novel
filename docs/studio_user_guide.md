# VibeNovel Studio 使用手册

适用：3.0.0a12 / Studio alpha。更新：2026-10-20。

这份手册按当前界面和实现编写。软件仍在演进，设计文档中的后续功能不代表当前已经提供。下文的“生成”“启动”会发送模型请求；保存构思、导入文件、本地检查、检索和生成预览本身不调用付费模型。

## 1. 先找到你需要的入口

顶部选择当前作品，点击“创建新作品”可开始另一部小说。没有作品时仍可整理个人资料库。

顶部“使用手册”可以随时打开本文，并提供构思、规划包、写前包与资料中心的快捷入口。离开有未保存内容的页面前，先保存或明确放弃修改。

| 你现在想做什么 | 左栏入口 | 下一步 |
| --- | --- | --- |
| 只有一个想法，想从零写小说 | 故事设计 → 创意与定位 | 填故事想法，保存构思，预览并生成总纲 |
| 已有自己或其他模型写好的大纲 | 故事设计 → 大纲与卷章 | 导入/粘贴大纲，创建规划包 |
| 看人物、设定、关系 | 故事设计 → 人物与世界 | 选择规划包，再切换人物表、规划关系、故事设定 |
| 看后续事件安排和伏笔 | 故事设计 → 时间线与伏笔 | 选择规划包，切换计划时间线、伏笔台账 |
| 看规划文风 | 故事设计 → 写作风格 | 查看规划包内的文风安排 |
| 写或修改某一章 | 写作校订 → 章节写作 | 打开已保存文稿，使用右侧创作助手 |
| 准备写前材料或做本地检查 | 写作校订 → 审稿与检查 | 写前包、本地审稿、固定样章、历史检索等页签 |
| 分析、降低套话或修订已有小说 | 写作校订 → 已有小说修订 | 导入原稿，校正分章，创建独立修订副本 |
| 审阅 AI 或人工提出的正式变更 | 作者决定 → 待审变更 | 审阅差异 → 作者批准 → 应用到目标文件 |
| 配置模型、密钥、分工和作品预算 | 辅助工具 → 模型与角色 | 保存模型配置，再保存作品策略 |
| 找已保存的大纲文件 | 辅助工具 → 大纲文稿 | 打开来源、候选或已批准文稿 |
| 管理参考书、素材、技法、方法 | 辅助工具 → 资料中心 | 选择个人资料库/本书资料架和对应页签 |
| 查看正式人物状态和故事事实 | 辅助工具 → 正式设定与记忆 | 正式文件只读，修改需提案 |
| 找生成结果、错误、暂停或恢复操作 | 辅助工具 → 任务记录 | 选择任务，查看状态、版本和实际材料 |

“人物与世界”“时间线与伏笔”“写作风格”是同一个规划包的不同查看入口，不会分别自动创建内容。“写作风格”里的规划要求与“固定样章”里的实际文字参照也分别管理。

## 2. 第一次配置 API 与价格

目前生成统一使用 API，不需要 Codex 交互接力。密钥只在本机设置页填写；保存后不会回显。不要把密钥粘贴进聊天、普通文稿或资料卡。

### 只用一个 API

在创作助手点击“单 API 设置”，或在任务页面的“模型设置”进入“模型与 API 设置”弹窗：

1. 选择服务商，核对 Base URL 和模型 ID。豆包可按实际服务配置接入点 ID。
2. 在模型 ID 下方填写“输入价格（美元／百万 Token）”“输出价格（美元／百万 Token）”。研究的金额预算依赖这两项；留空代表未知，不代表免费。
3. 首次填写 API Key；同一地址已有密钥时，留空会保留原值。
4. 点击“保存配置”。保存不测试连接，也不触发生成。

价格使用当前模型的美元报价。若服务商按人民币报价，先换算为美元；采用未命中缓存、峰时价格可做保守预留。更换服务商、地址或型号会清空旧报价，需要重新填写。实际费用以服务商账单为准，Studio 展示的是按 Token 和所填价格计算的估算。

本机文件：`config/api.local.json`。支持的 JSON 示例是 `config/api.example.json`；真实配置和备份不进入 Git。

### 使用多个模型或按职责分工

进入“模型与角色”（页面内也称“多模型协作”）：

1. 如仍用单 API，可点击“复制原 API 配置”显式迁移；不会自动迁移。
2. 点击“添加模型配置”，填逻辑 ID、显示名称、Base URL、模型 ID、密钥、上下文和输出上限、输入/输出报价，勾选“允许用于”的职责，然后“保存模型配置”。
3. 在“本作品角色与预算”分别为规划、正文与编辑、证据审稿、候选记忆抽取选择主模型。可以复用同一模型。
4. 根据需要设置技术备用，填写流程调用次数、Token、费用预算和单节点尝试次数，点击“保存作品策略”。

启用多模型后，以模型注册表和作品角色绑定为准；单 API 弹窗会引导返回模型配置页。更换模型配置或报价后，旧任务预览可能失效，请重新预览。

### 三种预算分别在哪里

| 工作 | 配置位置 | 金额与模型来源 |
| --- | --- | --- |
| 总纲、规划、起草、审稿、普通资料分析 | 模型与角色 → 本作品角色与预算 | 所选作品的角色策略；单 API 兼容路径使用单 API 报价 |
| 参考书架 → 逐章研究 | 本批表单 + 真实计费作品 | 本批总上限和该作品共享预算同时限制 |
| 精读与结构图、跨书比较、方法效果评阅 | 资料中心 → 研究预算 + 每项研究表单 | 独立研究账户共用累计上限，与创作作品预算分开 |

独立研究预算页要单独选研究模型，填写输入/输出单价、报价来源与核对日期、共享总上限和累计请求数，再点击“保存研究预算”。仅在模型设置里填报价，不等于配置了独立研究账户。

## 3. 从零构思，生成并选用总纲

1. 顶部“创建新作品”→“从零构思”→“创建作品”。可先不定书名，作品文件夹标识默认自动生成。题材规则可选足球、冒险、校园、架空历史或通用创作。
2. 在“创意与定位”填写“你的故事想法”。一句话也可以；这是生成时唯一必填的故事内容。
3. 按需展开阅读/内容标签、主角与叙事、特殊优势与开局、篇幅文风等部分。标签可包含、避免或未定；没有金手指和还未决定分别保存。
4. 点击“保存构思”。未配置 API 也能保存。添加自定义标签后要点击“添加标签”，再保存。
5. 点击“预览生成”，核对当前简报版本、模型、资料、尝试次数、Token 和预算。
6. 点击“生成初版总纲”才开始模型任务。结果在“总纲候选与下一步”及“任务记录”中保留。
7. 阅读候选；如需修改，点击“打开编辑器修改”，保存后回到构思页核对版本。
8. 点击“选用这版继续规划”。这只是选择后续规划依据，不是批准章计划或正式事实。
9. 点击“创建规划包”，进入下节流程。

修改构思或候选后，旧选用可能失效。需要核对并重新选用，不能直接沿用旧预览。

## 4. 已有大纲，以及“规划包”究竟在哪里创建

**进入“故事设计 → 大纲与卷章”，在“创建规划包 · 导入或选择大纲”表单中操作。** 没有规划包时，表单自动展开，填写后点击“预览规划包”。从构思页选用总纲后，可使用页面上方的“创建规划包”入口带入该总纲。规划包下拉框只查看已有包；已有包时，工具栏的“新建规划包”可重新展开创建表单。

一份规划包把选定大纲整理为全书/卷概述、本批章计划、人物、关系、伏笔、计划时间线、故事设定、写作风格及待确认点。它描述未来安排，不表示剧情已发生。

### 导入或粘贴大纲

1. 新建时选择“已有大纲”，或打开现有作品的“大纲与卷章”。
2. 点击“导入已有大纲”选择 MD/TXT 文件；原件和提取稿分别保留。也可点击“粘贴或手写大纲”，保存为工作文稿。
3. 在“创建规划包”表单的“来源文稿”选择导入提取稿、源大纲或候选大纲。

网页普通大纲导入上限为 10 MiB。大型参考小说请放入“参考书架”，不要把整本参考小说当作本书大纲或正式故事事实。

### 创建并审阅规划包

1. 填“起始章节”和“本批章数”，每批 1–10 章，建议先用 1–3 章验证。填写作者要求可以约束主线、人物、时间或文风。需要参考资料时，先按下文“为这次规划挑选资料”的步骤明确选择，再预览。
2. 点击“预览规划包”，核对来源、实际材料、模型和预算。
3. 在弹窗点击“确认并生成规划包（付费）”。结果先是候选包。
4. 等待完成；在下方“规划包”选择结果。也可从“任务记录”查看进度或错误。
5. 依次审阅“总览与卷章”“人物表”“规划关系”“伏笔台账”“计划时间线”“故事设定”“写作风格”“待确认点”。来源明确陈述、根据来源推断、新增建议分别标示；引用可回查。
6. 如需调整，点击“修订候选 JSON”。当前按整份 JSON 编辑，尚无人物等条目的独立编辑器。
7. 点击“提交整包审批”，到“待审变更”审阅后点击“作者批准”，再点“应用到目标文件”。批准和应用是两个步骤。
8. 回到“大纲与卷章”，选择“已应用”的有效包。在本章卡片点击“提取章计划”。
9. 再到“待审变更”，单独批准并应用章计划。整包获批不能代替独立章计划批准。

同一时间已有章计划提案未处理时，先应用或驳回，再提取下一章。来源或依赖变化导致包失效时，保留旧包供回看，不能继续提取有效计划。

### 为这次规划挑选资料

在规划表单中找到“为本次任务选择资料与方法”：

1. 在卡片列表勾选本书资料，或个人资料中已经“用于本书”的固定版本。可按标题、摘要或类型筛选；“刷新可选资料”重新读取列表。仅本地、已撤回/归档、未采用方法、用途不合或来源失效的项会给出不可选原因，先到资料中心处理。
2. 需要书中的具体安排或表达时，点击“从参考书检索选段”。弹窗内选择已建立的索引，输入具体问题，点击“检索资料”。它不会离开规划表单。
3. 勾选有用片段，点击“预览用于任务的精确资料”，核对实际文本，再点“将所选片段加入当前任务”。卡片选择会保留；新的检索选择替换上一次固定检索选择，可用“移除检索选择”撤去。
4. 如果尚无可用索引，按提示先到“资料中心 → 语义检索”建立本地索引（第7节），再回来选择。仅导入参考书还不足以进行语义检索。
5. 改选后重新点击“预览规划包”。弹窗里的“本次资料与方法”显示最终组合，展开“实际补充文本与版本”核对；如需改选，点击“返回选择本次资料”，不会因此启动模型。

本次勾选不会修改已保存的选材政策。本书为有界自动模式时，仍可能按原政策补充其他材料，最终以预览清单为准；希望只用自己勾选的资料时，先将本书政策设为手动，再明确勾选。选材不自动采用方法、放宽外发权限或把整本参考书发送给模型。

作者要求用来表达目标，例如“以《足球豪门》的长期经营推进作为主要研究方向，其他参考仅用于对白与情绪表达”。**只写书名不会自动检索书库、阅读该书或发送原文**；模型本身可能认识书名，但这不代表它用了本机收藏的版本。

资料可分工搭配，而无需把所有参考书整本装入提示：

| 参考作用 | 应选择的内容 | 使用边界 |
| --- | --- | --- |
| 主要的足球经营与内容安排参考 | 《足球豪门》中与当前卷/章问题有关的精确原文片段，以及作者已核对采用的结构方法卡 | 用来研究经营目标、阶段升级、比赛与经营的交替安排；不直接搬用人物和情节 |
| 辅助的通用表达参考 | 已采用的对白、细节、节奏或情绪表达方法卡；按需补少量能核对的证据片段 | 只辅助表达，不能把另一本书的世界观、人物状态或情节当作本书事实 |
| 本书创作要求 | 当前总纲、作者硬条件、有效规划和已确认材料 | 决定本书要写什么；外部参考不能覆盖作者约束 |

先确认这些方法或资料在本书范围内可用，原文片段有明确外发授权。每次以“实际补充文本”为准，资料不是越多越好。候选方法、未授权或已失效内容不能仅因为作者写了书名就绕过门禁。

任务预览中的“本次资料与方法”是**本次实发内容的核对清单**。它不会仅凭同名资料自动增加输入。某一项标为“未发送”，表示它没有进入本次补充文本，例如自动可选资料超出剩余预算或来源失效，具体原因看该项说明。手动明确选择未授权、未采用或失效资料会阻止预览，不能按未发送后继续使用。“已纳入”也只表示纳入当前预览，仍要明确确认任务，才会发给模型。

还有一种情况是**方法卡已纳入，研究原文仅作为来源依赖、未自动发送**：模型会收到卡片的步骤或作者摘要，但不因此收到卡片关联的整章或整本书。希望它同时分析某段原文，应通过“从参考书检索选段”显式加入，而不是将来源书名当作已读证据。

## 5. 从章计划到正文与定稿

推荐顺序：**有效章计划 → 写前包 → 草稿候选 → 审稿与修订 → 定稿提案 → 作者批准 → 应用。**

### 准备与起草

1. “审稿与检查 → 写前包”选择“已批准并应用的章计划”，选择精简或完整范围，点击“整理写前包”。这里列出实际承接材料和省略项，不调用模型。
2. 到“章节写作”打开一份已保存的文稿；起草任务仍要求当前上下文文稿和独立有效章计划。
3. 展开右侧“创作助手”，选择起草任务，选择“已批准的章节计划”和写前包模式，填写目标。
4. 点击“开始任务”，核对任务预览后明确确认。起草时会重新核对最新材料；页面里先前展示的写前包不是永久冻结的生成权限。
5. 在“任务记录”打开生成结果。结果是草稿，可编辑保存并保留历史，不自动写入正式章节。

可以在编辑器直接保存工作草稿；正式正文、正式设定和记忆只读。

### 两类审稿

| 方式 | 入口与动作 | 能提供什么 |
| --- | --- | --- |
| 本地检查 | 审稿与检查 → 本地审稿 → 选择已保存文稿 → 分析已保存版本 | 套话、字面重复、句段及样章指标等线索；不调用模型 |
| API 审稿/改写 | 当前文稿的创作助手，或模型与角色中的候选协作流程 | 独立候选审稿与改写；先核对模型/预算，发送后计费 |

本地报告可标记待处理、已处理、已忽略，并点击“按当前版本复查”；作者标记不会修改正文，也不证明语义问题已解决。文稿修改后，旧报告仍保留但显示过期。

“固定样章”由作者明确勾选 1–10 份草稿或定稿，再“保存样章选择”；样章变化后需重新确认。历史检索只搜索正式章节，不把草稿当作已发生事实。

### 正式定稿与记忆

1. 工作文稿编辑器点击“提交定稿提案”，核对目标，例如 `chapters/ch001.md`。
2. 填变更理由和影响范围，查看差异，点击“提交审批提案”。更改目标后须先“核对目标”。
3. “待审变更”中审阅差异或提案全文，点击“作者批准”，再点“应用到目标文件”。应用时再次核对目标版本。
4. 正式记忆或设定需要更新时，在“正式设定与记忆”打开相应文件，点击“提出修改”，分别提交并审批。

当前是逐文件审批；章节与多份记忆尚无一次性原子定稿事务。候选记忆抽取也不会自动写入正式记忆。

### 按角色协作与双稿盲评

“模型与角色 → 候选协作流程”选择已保存文稿，填写编辑目标，按需勾选后续证据审稿、候选记忆抽取，再“预览首节点路线与预算”→“启动候选流程”。首个编辑节点发送后，后继在“明确启动下一节点”处等待作者；不会一次自动串起全部模型。需要至少为所选节点保存足够的调用次数和 Token 预算。

证据审稿返回后，可勾选重叠或相邻的精确问题，点击“按所选证据启动局部修订”；最多两轮，修订和复审仍占原流程预算。新正文版本会使旧审稿失效。需要处理分离的多处问题时分开选择，不让局部改写越过未选范围。

同页“作者盲评 · NovelBench”比较两份明确选择的草稿：选来源一/二→“锁定版本并随机对照”→作者阅读 A/B 并投偏好→“显式揭示来源”。也可“导出匿名对照”。该比较不调用模型，与资料中心的四请求方法效果试验不同；不自动采用稿件、排名模型或训练路由。

## 6. 已有小说的分析与修订

1. “已有小说修订 → 导入原稿”，保留来源。
2. 选择原稿来源，点击“预览分章”。识别不合适时填写各章起始行，再预览；页面可每次查看 100 行以核对。
3. 点击“创建独立修订副本”。后续修改只发生在副本里，原件保留。
4. 打开副本，选择章节。可“检查勾选章节”或“分批检查全稿”；每批最多 20 章、50 万字符，为本地规则检查。
5. 需要 API 审稿或表达修订时，明确选择全章或拖选文字的精确范围，填写目标，先预览再确认。
6. 阅读改写差异，点击“接受到本章修订副本”。未接受的候选不替换副本。
7. 完成后点击“独立导出”。需要纳入正式章节仍应另走正式审批。

“降低 AI 味”应转成可判断的目标，如减少套话、通过动作代替解释、区分角色口吻、保留情节事实。系统不能凭一个分数保证文字由人创作或文学质量达标。

## 7. 资料中心：从收藏到真正用于写作

### 普通资料与方法卡

“资料中心”可切换“个人资料库”和“本书资料架”。前者跨本书收藏，后者是当前作品范围。六类卡是文献、素材、技法、风格、术语、方法。

1. 用“导入资料”收录 MD/TXT（最多 10 MiB），或“新建卡片”写作者笔记。
2. 补书目、摘要、标签、专题、核对状态和模型外发政策；保存不意味着已核对或允许外发。
3. 想用模型提炼方法时，在来源详情选择精确片段、用途、真实计费作品，点击“预览资料分析”，确认后“开始分析所选资料”。
4. 分析成功后“查看并复用分析”→“预览提炼方法”→“开始提炼方法候选”。两个阶段共用原流程预算。
5. 方法卡先是未采用候选。核对用途、步骤、输入输出、限制、反例和原句，修改保存后由作者采用。编辑后需重新采用。
6. 在个人卡详情选择用途并点击“用于本书”。该动作固定一个版本，不会随着个人库后续编辑静默更新；规划参考用途的固定资料可在创建规划包时勾选。
7. 本书“任务选材”决定手动、仅推荐或有界自动。要让普通资料在网页创作任务中自动装配，需明确保存有界自动策略，并限制类型、用途、数量、字符预算和必选/排除项。

收藏、采用、用于本书、用于一次任务是不同动作。推荐列表不会自动发送给模型。有界自动也只使用本书和作者明确选入的资料，不会扫描其他小说。

### 参考书架的两条研究路线

整本参考小说通过“参考书架 → 导入参考书”收录 EPUB/TXT/MD（单原件最多 128 MiB）。原件、解析版和技术分册保留；技术分册不等于原书卷，解析章段数不等于出版章数。

先在“原文与目录”核对，再到“核对与外发”检查异常；需要模型研究时，明确允许“发送明确选中的章节片段”并“保存外发设置”。有编码缺口或控制字符的章段不会自动进入研究。

| 路线 | 适合用途 | 启动顺序 |
| --- | --- | --- |
| 参考书架 → 逐章研究 | 对明确章段做独立观察，再层级归并本批结构、表达和方法 | 选章段/计费作品 → 预览 → 保存研究批次 → 开始研究（付费） |
| 精读与结构图 → 新建研究 | 按原书顺序连续精读、针对证据主动补读、围绕同题跨书比较 | 配好研究预算 → 选方式/书/范围 → 预览精确范围与报价 → 保存为待启动研究 → 启动精读 |

两条路线不能混同：逐章独立观察不等于带前文检查点的连续精读。连续精读提供因果、人物、线索、情绪节奏四组候选图和当时知情检查点，历史上下文仍有边界。

逐章研究中按钮始终可见。填写报价、授权、范围和预算后，依次点击“2. 预览范围、模型与总预算”“3. 保存研究批次”“4. 开始研究（付费）”。保存只得到“已准备，等待启动”，没有开始付费；下方历史批次也保留控制按钮。完整正文按钮只选当前目录页，跨页选择会保留。

在连续研究中，跨书比较至少选择两本书的明确原文；单书最多 24,000 字符，总计最多 48,000 字符。回查证据后可“建立上下文补读”，补读独立存证，不改写初读时点。缺书或缺授权时，使用“参考书架：导入与外发授权”；缺模型、报价或共享上限时，使用“设置研究模型、价格与总预算”。“刷新研究状态”会重新读取书架、研究列表和当前工程；编辑图谱前先暂停运行中的研究。

研究成功后，在方法候选中预览并“保存到个人方法候选”，或逐章研究结果的“整理方法候选”。入库本身不调用模型，随后仍需作者核对、采用、用于本书与任务选材。

### 语义检索如何进入任务

1. “资料中心 → 语义检索”选择书籍和原文、结构、表达、已采用方法等资料层。
2. 点击“预览索引范围”，再“确认建立本地索引”。需要本地 BGE 能力；页面不会偷偷联网下载或改用收费模型。
3. 选择就绪索引，输入研究问题，选择语义召回/证据图关系和资料层，点击“检索资料”。
4. 勾选有用片段，点击“预览用于任务的精确资料”，核对实发文字，再“用于本书下一次任务”。
5. 回到创作任务入口重新预览模型、预算与资料。该选择不等于已发送；来源或授权变化会要求重新选择。

来源、图谱或方法发生变化时，索引可能失效，需重新构建。相似度和图关系提供核对线索，不证明事实正确或方法有效。

### 目录整理与方法效果评阅

参考书内“目录与修订”可建立拆分、合并、排序、隔离和精确补丁的派生版本。先预览再发布；原件与旧版保留，不能靠整理目录把缺文变成已修复。

“方法效果评阅”选择已有成功研究中的 1–6 个方法，填写全新练习简报、金额和输出上限。“预览四次请求与预算”→“保存评测，稍后启动”→“开始 / 继续未发送请求”。三份条件练习加一次匿名 AI 评阅共四次请求，受独立研究账户限制。作者亲自阅读样本后再保存偏好评价并揭示条件；单次试验不证明方法普遍有效。

## 8. 任务中断、错误和找不到下一步

| 现象 | 先检查什么 |
| --- | --- |
| 规划包列表是空的 | 到“大纲与卷章”的“创建规划包”，选择来源并生成；列表只显示已产生的包 |
| 人物/时间线/文风页没有资料 | 这些页面读取规划包，不会自动生成；先创建一个有效包 |
| 规划包有了，起草仍无章计划 | 整包提交审批、批准并应用后，还要逐章“提取章计划”，再批准应用 |
| 看不到研究开始操作或按钮不可用 | 先完成范围/报价/授权/预算预览，再保存批次；检查按钮旁的原因，并查看下方已有批次 |
| 报输入/输出价格未配置 | 单 API 在模型 ID 下填写；多模型在模型配置中填写；精读/比较/效果试验还要保存独立“研究预算” |
| 预览后改了选择，确认按钮失效 | 对当前范围和配置重新预览；旧预览不能授权新输入 |
| 来源或报告显示过期 | 重新读取最新版本并预览/检查，旧资料保留为历史 |
| 关闭网页后不知道任务在哪里 | 打开“任务记录”，或资料中心对应研究工程/评测列表 |
| 请求结果不明 | 先查原任务/批次，不要反复新建；保留原键核对，未知费用不按零清除 |
| 旧任务重试提示调用次数或预算耗尽 | 重试继续使用原预算组，不会因修改当前策略而清零旧费用。先核对原记录；确需另做一次时，回对应任务入口，对新任务重新预览并明确启动 |
| 规划 JSON 无效 | 在任务记录或候选修订入口核对原响应并修复；离线修复不重新收费 |
| 正式文件不能直接保存 | 用“提出修改”创建提案，到待审变更批准并应用 |
| 页面很长 | 鼠标移到需要操作的主区或侧栏滚动；侧栏可收起。若仍不能滚动，记录页面、窗口大小与区域反馈 |

关闭网页不会停止仍运行的后端任务。暂停阻止后续请求，已经发送的请求可能仍会返回并计费。停止后端后不会自动重放未知或失败请求；不要把刷新页面或恢复候选当作重新付费的理由。

## 9. 导出与备份

顶部“导出作品”只导出已应用的正式章节：填写起止章或留空全部，点击“下载 Markdown”。工作草稿可在编辑器“下载当前文稿”，修订副本用“独立导出”。文稿导出不是完整备份。

完整备份应在暂停写入后包含：

- 整个 `novels/<作品ID>/`，包括 project、草稿、正式章节、记忆、历史、提案、任务及 `.runtime/` 预算/路由。
- 整个私人 `library/`，包括原件、旧新解析版、映射、方法卡、研究批次、检查点、结果、索引、研究账户与 journal。
- 本书资料架及其依赖的个人库；只复制单本小说目录不足以恢复跨库引用。
- 本机配置 `config/api.local.json` / `config/models.local.json` 按需单独安全备份；这些含凭据，不上传 Git，不混入可分享的资料包。

当前尚无网页“一键完整备份/恢复”流程。不要只备正文或向量索引，也不要在恢复后自动重放旧付费任务。

## 10. 当前边界

当前编辑器保存 Markdown；尚无 Tiptap 富文本与行内批注、DOCX/PDF 导入导出、Windows 桌面封装、人物等规划条目的独立编辑、多文件原子定稿。研究资料不会自动训练模型，也不会自动替换样章或成为故事事实。

程序能验证版本、权限、预算和引用位置；作者仍负责选择大纲、批准计划、判断文学效果和最终定稿。实现与数据边界以 [实施计划](implementation_plan_v3.md) 和 [存储合同](storage_contract_v3.md) 为准。
