## 三种小说参考各做什么

- 经典小说：观察可跨题材使用的组织方法，如人物登场、信息分配、动机/阻力、场景推进和伏笔；保留具体章回、版本和原句。
- 同类型小说：核对读者期待、职业/竞技线的展开方式、每阶段目标和题材惯例。首期只登记可验证书目；没有实际正文与定位时，不生成“全书拆解”。
- 作者认可的原创样文：用于本书声音、句法、对白、描写密度和禁用表达。资料中心风格卡与既有固定样章独立，是否设置为样章由作者决定。

收录公共领域原文和来源页；现代小说先收书目、阅读问题和作者合法提供的选段，不从不明站点批量搬运正文。保存原文版本、译者/编辑信息与来源；中文译本不是外文原著的同一个文本版本。

## 让模型有效使用

1. 原件作为可回看的证据。先选章回/场景和明确问题，再分析；全文收藏不代表全文已读。
2. 分析卡解释“哪里发生了什么、由哪些原句支持”；方法卡进一步表达输入、步骤、输出、适用情境、边界与反例。两者都保留精确范围。
3. 将抽象机制迁移到新场景。比如群像登场的观察可转成“按同一目标引入三名不同立场角色”的规划检查；原作人物、句子和具体情节不作为待复写模板。
4. 方法先由作者编辑采用。个人卡须选入本书，并允许适当外发；随后才由书级有界自动政策在用途、条目和字符预算内装配。任务预览显示真正发送的内容。
5. 为不同任务选择不同信息：规划用结构/人物/因果方法；起草用少量事实卡与表达要求；审稿用证据和方法检查；改写保留事实与视角。当前首期按词项召回，标题/摘要/标签使用具体任务词，不承诺语义理解全部资料。
6. 输出仍是独立候选。先检查是否正确使用参考、是否改变本书事实，再由作者决定。后续L2-C可增加有/无方法对照；当前没有自动方法效果分。

本批只创建资料、问题和未采用候选，保留书级原政策，不自动外发、采用方法、设置固定样章或触发真实付费任务。库不入Git，完整备份须包含工作区个人库和所依赖的本书库。
